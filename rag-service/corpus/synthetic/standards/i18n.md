# Standard i18n (synthétique — projet personnel)

## Principe
Toute chaîne visible par l'utilisateur doit être externalisée. Aucun texte en dur dans le template ou dans le contrôleur.

## Structure attendue pour fake-exposer
- `public/i18n/fr.json` et `public/i18n/en.json` : dictionnaires plats `cle: texte`.
- Une fonction `t(key)` côté client lit le dictionnaire courant.
- Le choix de langue est stocké dans `localStorage` sous la clé `pfe-lang`.
- Valeurs autorisées : `fr` par défaut, `en` pour l'anglais. Aucune autre locale.

## Règles de nommage
- Clés en minuscules, mots séparés par des points : `header.title`, `button.analyze`.
- Une clé absente du dictionnaire courant retombe sur `fr.json`, jamais sur un texte en dur.

## Validation
- Un test `node:test` vérifie que changer la langue modifie au moins un libellé visible.
- Un test vérifie que la valeur persiste après rechargement simulé de la page.
- Aucune dépendance npm supplémentaire n'est autorisée pour cette fonctionnalité.
